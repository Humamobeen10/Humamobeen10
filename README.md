I'm a Frontend Developer with over a year of professional experience building web applications in React.js. I finished my BS in Computer Science at Virtual University of Pakistan in 2025.

At Real Science School I built the frontend of the school's management web portal: dashboard, admissions, student records, attendance, timetables, fee status, exam results and notices. I turn Figma designs into reusable React components, connect them to REST APIs, and keep the interface fast and responsive on every browser.

Happy to talk React, component design, or turning a design into a working UI. Reach me at mobeenhuma9@gmail.com.

## 🚀 What I've Built

**School Management Web Portal** · Real Science School, A Group of Real Educators

- Multi-step admission form with student and guardian details, previous school records, class selection, and document and photo uploads
- Admissions list where staff can search, filter, view and edit students, with print and export
- Role-based screens and navigation with React Router, so each user type sees only their own pages
- Validated forms for attendance entry and fee records, backed by live REST API data
- Faster page loads and better cross-browser support across the whole portal
